ABOUT THE PROJECT

Making cab management smarter

Managing cabs, assigning rides and finding efficient routes can be challenging. RideWise uses four important algorithmic techniques to solve these problems through an interactive Java Swing desktop application.

ALGORITHM MODULES

Four algorithms. One smart system.

Each module solves a different cab management problem using concepts from DAA Unit II.

01 • DIVIDE AND CONQUER

Closest Pair of Points

Identifies the nearest available cab to a passenger using their coordinate positions.

O(n log² n)
02 • GREEDY ALGORITHM

Job Sequencing

Schedules ride requests within their deadlines to maximise the total reward.

O(n²)
03 • MINIMUM SPANNING TREE

Prim's & Kruskal's

Finds a minimum-cost network connecting all city hubs through road connections.

Prim: O(E log V)
04 • SHORTEST PATH

Dijkstra's Algorithm

Finds the shortest route between city locations using road distances.

O((V+E) log V)
